# Portfolio de Asier Arrondo Abasolo

Portfolio personal adaptable, desarrollado con HTML, CSS y JavaScript nativos.

## Desarrollo local

Abre `index.html` en un navegador para ver el sitio. No requiere dependencias ni proceso de compilación.

## Archivos

- `index.html`: contenido y estructura del portfolio.
- `styles.css`: estilos y diseño responsive.
- `script.js`: menú móvil y año del pie de página.
